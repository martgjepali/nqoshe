# Image provenance

**Every image in this directory is synthetic.** All of it was generated for this
demo with Google Nano Banana 2 (2K) via the Higgsfield API on 2026-09-21. None of
it shows the real interior of any real café in Tirana, and none of it should ship
to a visitor as if it did.

**Before this goes anywhere public, replace all of it with real photographs of the
actual places.** Until then, the footer on the landing page says so out loud, and
that disclosure has to stay.

A shared style suffix was appended to every prompt below:

> Shot on 35mm film, natural directional light, warm grade built from cream,
> espresso brown, terracotta, brass and olive. Shallow depth of field, soft film
> grain, no people, no readable text, no signage, no logos, no watermark.

Each source render was 1856x2304 (4:5) or 2752x1536 (16:9), downscaled and
re-encoded to WebP with ffmpeg (`-quality 82`, hero `85`).
